Fikra — Gamified Software Development Learning Platform
Status: Under active development

Fikra is a mobile-first platform designed to help students and beginner developers learn software development by building real projects. It combines guided development tasks, gamified progression, and collaborative project workflows.

Project Overview:
Instead of learning concepts only through isolated exercises, Fikra is designed to guide learners from a project idea to a technology stack, a development roadmap, and progressively challenging coding levels.

Core Workflows:
Project-based learning:
> Submit and explore software project ideas.
> Generate or refine technology recommendations and development roadmaps.
> Follow a structured learning path consisting of 60 sequential coding levels.
Gamified progression:
> Track level progress and attempts.
> Use hints while working through coding challenges.
> Earn XP and unlock subsequent levels as progress is made.
AI-assisted guidance:
> Support project analysis and clarification workflows.
> Assist with technology selection and roadmap generation.
Collaboration:
> Join projects and participate in shared development tasks.
> Assign work, submit code contributions, and support reviews.
> Provide project-owner approval workflows for contributions.
These are the project's development goals and ongoing workstreams. They do not imply that every workflow is complete or production-ready.
